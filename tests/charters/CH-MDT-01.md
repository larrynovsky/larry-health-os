# CH-MDT-01 — «Раунд B действительно слышит коллег»

**Linked UC:** UC-H-03 (Раунд B используется содержательно).
**Запуск:** после инцидента в этой подсистеме (решение 2026-07-02: расписание не ведётся — ежедневное чтение утреннего отчёта покрывает CH-DAILY; остальные чартеры — процедура постмортема).
+ при подозрении на «Раунд B = повтор Раунда A».
**Длительность:** 20-30 минут.

---

## Маршрут ревью

### Шаг 1: Собрать 3 разные `/consult` сессии

Желательно — на разные темы (сон, питание, химиотерапия).

### Шаг 2: Прочитать оба раунда подряд для каждого специалиста

Для каждого из 13 специалистов:

1. **Round A (independent):** какое мнение?
2. **Round B (sees colleagues):** появились ли:
   - ссылки на коллег («согласен с [онколог]», «не согласен с [нутриционистом]»)?
   - изменение позиции с обоснованием?
   - новые аргументы из чужого взгляда?

### Шаг 3: Если Round B = механический повтор Round A

Это fail. Council не deliberative — просто двойной прогон.

### Шаг 4: Дополнительно (UC-H-03 структурный)

Можно использовать embedding-similarity:
- cos_sim(Round A text, Round B text) > 0.95 для >80% специалистов = alarm.
- Реализация — отдельный e2e_mock тест в Фазе 4 (skipped пока).

### Шаг 5: Логирование

Если fail — proposal на пересмотр Round B prompt.
