## Where the paths are defined

The installation's cloud folder is `infra_config.CLOUD_HEALTH_DIR` (the `cloud_health_dir` key in
`private/infra.yaml`). Modules obtain paths inside it through `infra_config.cloud_dir(...)`:
`CR/` (reports the owner places there manually), `data/hae_archive/`, `data/Fitdays*.csv`,
`data/reports/`, `reports/`. No key (new installation) → the same paths in the process's data directory
(`HEALTH_DATA_DIR`); documents arrive through the bot in `incoming/`.
The Health Auto Export app folder is `infra_config.HAE_APP_DIR`. A literal cloud path outside
`infra_config` and the guards makes `test_cloud_literal_only_in_home` fail (since 2026-09-24, BL-PUB-12).

## Orchestrator

`import_all.py`. After a successful import, each module calls
`health_db.set_import_status(source)` — this is conit C1, used to calculate source freshness.

## Apple Health (HAE)

Daily JSON files are in `HAE_DAILY_DIR`:

```
~/Library/Mobile Documents/iCloud~com~ifunography~HealthExport/Documents/Health/
```

The `New Automation/` folder in the same container **is not used** — see C-32.

Processed files are archived with `shutil.copy2()` into `hae_archive/`.
`os.rename()` does not work across iCloud containers (C-33).

**Blood pressure.** Included in JSON only if Blood Pressure is enabled in
Settings → Metrics in the HAE app. The workaround is parsing the binary `.hae`
from AutoSync: regex on the ASCII markers `systol` / `iastol`, a cutoff range of
60–200 mmHg (C-34).

## Lab reports (JPEG/PDF)

`import_all.py` classifies a file as a lab report if **≥3 signals** match:

| Signal | What it looks for |
|---|---|
| analyte markers | `WBC` / `RBC` / `HGB` |
| numeric range | `\d+\.\d+\s*[-–]\s*\d+\.\d+` |
| source | clinic name from the tenant's `doc_patterns` |

On a match, `classify()` returns `"lab"` → `lab_extractor.extract_labs()` →
`data/pending_labs/` → a card in Telegram → after ✅, `health_db.import_from_pending()`
inserts into `lab_results` with `ON CONFLICT DO UPDATE`.

Manual entry (`LAB_DATA` in `import_medical_docs.py`) remains a backup path
for historical data without a digital original.

## Atomicity and resilience

- Writing: temp file → `os.replace()` (Tanenbaum §7.3.1).
- iCloud-evicted files are skipped with a warning (graceful eviction) without failing the import.
