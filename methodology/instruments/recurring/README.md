# Повторяемые опросники (reference)

В bundle входят isi.json и mfsi_sf.json: 7 и 30 вопросов, status paraphrase.
Вопросы и скоринг сохранены; перенос в образ не означает клиническую валидацию.
Узкоспециальные опросники — в каталоге тенанта.

Владелец чтения — assessment_scheduler.load_instruments / load_instrument.
Файл тенанта переопределяет одноимённый шаблон и является явным назначением:
фильтр применимости на него не действует. Отсутствие/повреждение bundle — ошибка;
отсутствие применимых шаблонов в исправном bundle — нормальный пустой результат.
Ответы остаются в данных тенанта. Одноразовые формы лежат уровнем выше и не планируются.

applies_when — ALL-of condition_id из clinical_kb.active_conditions текущего тенанта;
отсутствует/[] — всем. Планировщик, анализатор и оба ночных датчика вызывают
load_instruments(..., applicable_only=True); импортёр и диалог читают полный каталог
для явных действий и исторических ответов.
ISI/MFSI-SF: oncology — автоматический survivorship-набор, не универсальный скрининг; другим людям доступны по явному overlay.

Интервал — cadence_days шаблона; дефолт и запас — methodology/assessment_schedule.json.
Запас 14 дней перенесён из прежнего датчика свежести. Для применимого опросника
отсутствие всей истории — FAIL; открытая задача останавливает повторное производство.

Оракулы — tests/unit/test_assessment_scheduler.py: bundle, overlay, пустой каталог,
поставка файлов, интервал, регистрация датчика; ALL-of проверяется на выдуманных
Example-данных. Сборка образа и production-доставка этими тестами не проверяются.
