# Бот ответил «Не получилось ответить: сбой внутри системы…» с кодом

> **Жанр (Diátaxis): how-to.** Для того, кто сам поставил систему по
> [уроку установки](../tutorials/first_install.md) ([English](../tutorials/first_install.en.md)) и получил от бота такое сообщение.

Так бот отвечает, когда у него упала команда или кнопка, а других чинящих у вашей установки нет:
вы её поставили — вы её и чините. Бот при этом продолжает работать, спешить некуда. Код из
сообщения — шесть знаков, например `a1b2c3`. Он ведёт к записи о сбое на вашей машине.

## 1. Найдите запись о сбое

Из каталога установки (по уроку — `~/health-docker`) подставьте свой код:

```bash
cd ~/health-docker
docker compose exec -T cron sh -c 'grep a1b2c3 /app/logs/faults.jsonl'
```

Ответ — одна строка: когда (`ts`), где (`where`) и что случилось (`text`). Пусто — код набран
неверно или журнал уже обрезан (он хранит последние две тысячи записей).

Подробности с трассировкой — в журнале бота, рядом по времени:

```bash
docker compose exec -T cron sh -c 'tail -n 60 /app/logs/bot_err.log'
```

## 2. Попробуйте частые причины

| В записи | Что это | Что сделать |
|---|---|---|
| `Read-only file system` … `.health_secrets` | версия бота пишет в каталог ключей, а он только для чтения | обновитесь до последнего выпуска — раздел «Как обновиться» урока |
| `authentication_error`, `credit balance` | ключ Anthropic неверный или на счёте нет денег | шаг 4 урока: проверьте ключ и баланс, затем `docker compose restart bot` |
| `InvalidToken` | неверный токен Telegram | шаг 6 урока |

## 3. Не помогло — откройте задачу

Откройте задачу на [GitHub](https://github.com/larrynovsky/larry-health-os/issues/new) и
приложите:

- код сбоя и строку из `faults.jsonl`;
- версию: вывод `grep 'image:' ~/health-docker/compose.yaml | sort -u`;
- 20–60 строк `bot_err.log` вокруг времени сбоя.

Перед отправкой просмотрите текст: в нём не должно быть ключей и токенов. Медицинских данных
в журнале сбоев нет по устройству, но в трассировке может оказаться текст вашего сообщения боту —
его можно стереть.

## Почему бот не пишет подробности прямо в чат

Текст ошибки может содержать служебные адреса и куски ключей, а сообщения в Telegram часто
пересылают и прикладывают к задачам. Поэтому в чат уходит только код, а подробности остаются
на вашей машине.
