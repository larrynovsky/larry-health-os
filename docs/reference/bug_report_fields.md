# Что уходит в отчёт о сбое

> **Жанр (Diátaxis): reference.** Состав отчёта, который отправляет команда `/bug`
> (и `python3 -m bug_outbox`). Схема живёт в коде одна — `bug_report.py`; эту страницу сверяет с ней
> тест `tests/unit/test_bug_report_fields_doc.py`.

Ни одно поле не содержит свободного текста: каждое — перечисление, число или строка по узкому
шаблону. Отчёт не вычищается, а собирается только из этих полей.

| Поле | Что внутри | Пример (выдуманный) |
|---|---|---|
| `schema` | номер формы отчёта | `1` |
| `report_id` | случайный номер установки и порядковый номер отчёта | `3f9c0a7b5e21d4c8:4` |
| `release` | версия выпуска; `local` — собрано самостоятельно | `v0.2.2` |
| `platform` | система и архитектура | `linux/aarch64` |
| `category` | кнопка, выбранная человеком | `report_missing` |
| `connected` | подключено ли (да/нет), значения ключей не читаются | `{"oura": true, ...}` |
| `faults` | сбои журнала за 7 дней: тип, место в коде «файл:функция», сколько раз, отпечаток. У сбоя без исключения тип `none`, место — функция, записавшая сбой | `KeyError`, `labs_db.py:build_lab_history_context`, 3, `7f3a1c` |
| `screen` | названия шаблонов последних сообщений бота и время, без текста; сообщения самой команды `/bug` сюда не попадают | `07:30 jobs.brief.header` |

Значения `category`: `report_missing`, `button_silent`, `lab_not_read`, `other`.

Значения `connected`: `oura`, `apple_health`, `withings`, `genome`, `calendar`, `llm`.

## Что не уходит никогда

Тексты сообщений бота и ваших сообщений, текст ошибок (у ошибки бывает значение анализа или
ваши слова), имя тенанта, пути на вашей машине, любые ключи и токены. Адрес вашего компьютера
приёмник не сохраняет.

## Где хранится

У разработчика, в отдельном приёмнике без доступа к другим данным, 90 дней; затем удаляется
автоматически.
