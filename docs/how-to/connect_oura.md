# Как подключить кольцо Oura

> Тип документа: How-to (Diátaxis). Делает тот, кто ставил систему, на машине, где она работает.

Система берёт сон, вариабельность пульса и активность из Oura API v2 (`import_oura.py`). Ей нужен
личный токен доступа Oura. Импорт уже стоит в расписании: после того как токен положен, ничего
запускать и перезапускать не нужно.

1. Получите токен в личном кабинете Oura (раздел для разработчиков / Personal Access Tokens).

   Где именно он сейчас лежит, проверьте на сайте Oura: кабинет меняется. По сторонним источникам
   Oura сворачивает личные токены (называют конец 2025 года); на 02.10.2026 токен в установке
   автора системы работает. Если раздела с токенами в кабинете нет — напишите в
   [issues](https://github.com/larrynovsky/larry-health-os/issues): значит, этот путь закрылся и
   его нужно заменить.

2. Положите токен файлом `oura_token` в каталог ключей. В командах ниже замените `TOKEN` своим
   токеном, кавычки оставьте.

   **Установка в Докере** (по уроку [«Первая установка»](../tutorials/first_install.md)) — каталог
   `~/health-docker/secrets`, тот же, где лежат ключи Telegram и Anthropic:

   ```bash
   printf '%s' 'TOKEN' > ~/health-docker/secrets/oura_token && chmod 600 ~/health-docker/secrets/oura_token
   ```

   Этого достаточно на Маке и на большинстве Linux. Другая команда нужна только на Linux, где в
   шаге 4 урока вы отдавали каталог ключей пользователю 1000 командой `sudo chown`: тогда обычная
   запись в каталог не пройдёт, пишите через `sudo tee`:

   ```bash
   printf '%s' 'TOKEN' | sudo tee ~/health-docker/secrets/oura_token >/dev/null
   ```

   **Установка без Докера** — каталог `~/.health_secrets`:

   ```bash
   printf '%s' 'TOKEN' > ~/.health_secrets/oura_token && chmod 600 ~/.health_secrets/oura_token
   ```

   Для второго человека на той же машине — его собственный каталог ключей (как его заводят —
   [«Как добавить человека»](add_person.md)).

3. Проверка сразу, не дожидаясь утра (установка в Докере, из каталога `~/health-docker`) — забрать
   данные за последние 3 дня:

   ```bash
   cd ~/health-docker && docker compose exec -T cron python3 import_oura.py 3
   ```

   Ошибка в выводе значит, что токен не принят: проверьте, что в файле только токен, без пробелов
   и кавычек (`cat ~/health-docker/secrets/oura_token`). Без ошибки — через минуту на главной
   странице дашборда карточка «Сон и восстановление» покажет дату последней ночи. На следующее утро
   сон появится и в отчёте.

Токен не присылайте боту: сообщение Telegram хранится на чужих серверах.

Если ночи перестали приходить (карточка «Сон и восстановление» стала красной), чаще всего токен
отозван или истёк. Выпустите новый в кабинете Oura и замените файл той же командой, что в шаге 2.
