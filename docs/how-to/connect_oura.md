# Как подключить кольцо Oura

> Тип документа: How-to (Diátaxis). Делает тот, кто ставил систему, на основной машине.

Система берёт сон, вариабельность пульса и активность из Oura API v2 (`import_oura.py`,
фоновый сервис `com.larry.health.oura-import`). Ей нужен личный токен доступа Oura.

1. Получите токен в личном кабинете Oura (раздел для разработчиков / Personal Access Tokens).
   Где именно он сейчас лежит у Oura, проверьте на их сайте: интерфейс кабинета меняется.
2. Положите токен в каталог секретов этого человека одной строкой:

   ```bash
   printf '%s' 'ТОКЕН' > ~/.health_secrets/oura_token && chmod 600 ~/.health_secrets/oura_token
   ```

   Для второго человека на той же машине — его каталог секретов (`HEALTH_SECRETS_DIR` в его плистах).
3. Запустите фоновый сервис импорта (плист из `build/launchd/`, как в уроке установки, шаг 7).
4. Проверка: на следующее утро в отчёте есть сон за прошлую ночь.

Токен не присылайте боту: сообщение Telegram хранится на чужих серверах.
