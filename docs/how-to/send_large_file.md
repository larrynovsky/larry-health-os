# Как прислать боту большой файл

> Тип документа: How-to (Diátaxis). Для того, кто уже поставил систему и прошёл знакомство
> (урок установки, шаг 8). Разборщик присланных файлов (`com.larry.health.lab-intake`) запущен.

Telegram не отдаёт боту файлы больше 20 МБ. Такой файл — чаще всего сырые данные генома —
присылайте ссылкой на облако или путём к файлу на машине, где работает бот. Дальше файл
разбирается так же, как присланный в чат.

## Ссылкой на облако

1. Положите файл в Google Drive, Dropbox, Яндекс Диск или OneDrive. Других облаков, в том
   числе iCloud Drive, бот не знает. Архив `.zip` можно не распаковывать — разборщик
   заглянет внутрь сам.
2. Откройте доступ «всем, у кого есть ссылка» (просмотр достаточно).
3. Пришлите ссылку боту обычным сообщением.

Бот ответит «Принял ссылку», а когда скачает — «Получил «<имя файла>». Разбираю.».
Для генома через несколько минут придёт «Геном загружен: … вариантов».

Как только пришло «Получил …», доступ по ссылке можно закрыть: файл уже лежит у вас на машине.

## Путём к файлу на этом компьютере

Если бот работает на той же машине, где лежит файл, пришлите его полный путь, например
`/Users/вы/Downloads/genome.zip`. В Finder: правый клик по файлу, зажмите Option →
«Скопировать путь до …». Бот ответит «Принял путь», дальше — как со ссылкой.

Путь читается с правами того, под кем работает бот: бот может взять любой файл этой машины,
не только ваш. Если ботом пользуетесь только вы, это ничего не меняет. На машине, где у бота
несколько людей, это осознанное доверие между ними.

## Если что-то пошло не так

| Ответ бота | Что сделать |
|---|---|
| «Не смог забрать файл: файл не найден или доступ по ссылке закрыт» | Проверьте доступ «всем, у кого есть ссылка» и пришлите ссылку ещё раз |
| «облако вернуло страницу вместо файла» | То же: Google показывает страницу входа вместо файла, если доступ закрыт |
| «файл больше 3072 МБ» | Полный геном без сжатия может не влезть: пришлите `.vcf.gz` (сжатый VCF, в 4–5 раз меньше) |
| На ссылку с другого сайта бот отвечает как на обычное сообщение, «Принял ссылку» не пишет | Бот скачивает только из четырёх облаков выше — это защита машины. Переложите файл в одно из них |
| Формат генома не поддерживается | Поддерживаются сырые данные 23andMe, AncestryDNA, MyHeritage, FTDNA, tellmeGen (Starter/Advanced) и LivingDNA. Полный геном в VCF (`.vcf` или `.vcf.gz`, tellmeGen Ultra, «Атлас») разбирается, это занимает часы. VCF внутри zip не принимается — распакуйте. Сырые прочтения (FASTQ) не разбираются |

Второй геном поверх уже загруженного бот не грузит, чтобы случайно не затереть его чужим.
Заменить геном можно только вручную. Полный геном (VCF) поверх своего чипа — можно: он
уточняет генотипы. Если VCF заметно расходится с чипом (больше 0,5% общих позиций), бот
не пишет ничего и отвечает, что это, похоже, геном другого человека.
