# Формат квитанции замысла — нормативный дом

> ЕДИНСТВЕННЫЙ нормативный источник формата (reference, Diátaxis). Скиллы ритуалов
> (letitbe, the-end), реестр, сайдкары и сообщения гейта ССЫЛАЮТСЯ сюда и не
> пересказывают схему. Введён по внешнему ревью 2026-08-07 (F-02: прежняя ссылка вела
> в скилл вне репозитория). Машинный сторож: `tests/unit/test_intent_receipt_format_doc.py`
> исполняет примеры этого файла через живой судья `intentgate.evaluate_files`.

Квитанция живёт в секции `## Замысел` артефакта закрытия (план letitbe в `plans/PLAN_*.md`,
снимок handoff в `docs/handoff/**`) — yaml-блоком. Судья: `project_context/intentgate.py`
(pre-commit, exit 7). Правила: R1 секция и разбор · R2 id существует · R3 статус == живому
реестру из индекса · R4 `read_at` ISO-дата · R5 `none` требует reason · R6 полнота — снимок
несёт ВСЕ инварианты записи (введено по F-01: пустой словарь и «один удобный holds» — не
подпись чтения).

## Полная форма (планы и снимки handoff)

Ровно все инварианты каждой затронутой записи, статусы на момент чтения, дата:

<!-- example: full-valid -->
```yaml
intent:
  - id: alpha
    invariants: {a_holds: holds, a_open: open}
  - id: beta
    invariants: {b1: holds}
read_at: 2026-08-07
```

## Задача не касается ни одной записи

<!-- example: none-valid -->
```yaml
intent: none
reason: правка только документации ритуалов, кода подсистем не трогает
```

## Ревью-форма (`*.review.md`)

Только ids — ревьюер обязан читать живой реестр сам; авторские статусы для него —
утечка авторских допущений. Полнота (R6) здесь не требуется:

<!-- example: review-valid -->
```yaml
intent:
  - id: alpha
```

## Красные образцы (что именно режется)

Подмножество — не снимок (R6):

<!-- example: full-subset-invalid -->
```yaml
intent:
  - id: alpha
    invariants: {a_holds: holds}
read_at: 2026-08-07
```

Пустой словарь — нулевая подпись чтения (R6):

<!-- example: full-empty-invalid -->
```yaml
intent:
  - id: alpha
    invariants: {}
read_at: 2026-08-07
```

Протухший или подделанный статус (R3), `none` без reason (R5), отсутствие `read_at` (R4) —
режутся аналогично; формулировки — в сообщениях гейта.

## Границы (не пересказ — указатели)

Периметр суда, наследование снимка индекса и честные пределы (старт не стережётся; чтение ≠
понимание) — в записи реестра `intent_receipts` (`subsystem_intent.yaml`). Вне health:
скиллы letitbe/the-end несут этот же формат как образец; проект с собственным реестром
заводит свой дом формата по этому образцу.
