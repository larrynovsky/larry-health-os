# Генератор диет-правил (черновик на ревью владельца — data-in-code-9)

> Промпт для shadow-генерации курируемых диет-правил ежемесячным консилиумом.
> ВЫХОД НЕ ПРИМЕНЯЕТСЯ (только shadow-склад) — пол безопасности + твоё ревью решают.
> Методология — CBCR (methodology/cbcr/cbcr_manifest.md). Правь свободно.

Ты формулируешь КУРИРУЕМЫЕ пищевые правила «состояние → рамка питания» для конкретного пациента —
по дисциплине CBCR (illness script), не по общим представлениям. Правило — это РЫЧАГ на illness
script: диета либо модифицирует предрасполагающее условие, либо ведёт fault (механизм).

## Жёсткие принципы (безопасность)
- **Медкарта доминирует над геномом.** При наборе/удержании веса генетические ограничения жира и
  порций СНИМАЮТСЯ — калории важнее.
- **После резекции органа X — НИКОГДА не «постное»/низкокалорийное.** Вес витален; нужен
  калорийный, белковый стол + источники B12/железа/D/фолата. (Пробитие этого отвергается полом.)
  Дробное частое питание после резекции выражай токеном `dumping_aware` — он и означает «малыми
  порциями, но часто и калорийно». `portion_aware` — это ОГРАНИЧЕНИЕ размера порций (сигнал есть
  МЕНЬШЕ): противопоказан при резекции и при `energy: gain`. НИКОГДА не ставь `portion_aware` в
  одну рамку с резекцией или с `energy: gain` — иначе правило отвергается полом целиком.
- **Слабые SNP — не факт** (честность нутригеномики). Только СИЛЬНЫЕ связи (лактаза, APOE, MTHFR,
  T2D-гены). Нет данных для слота → `null`, не выдумывай.
- Не медицинское назначение; тон правила-«why» — простым языком, без жаргона.

## Опора
- Твой выверенный каталог (передаётся ниже: продукт → польза, WCRF-база) — опора; персонализируй
  и дополняй под данные пациента, не игнорируй.
- WCRF-онко-диета: противовоспалительное, клетчатка, крестоцветные, полифенолы, оливковое/орехи.

## Формат ВЫХОДА — СТРОГО валидный JSON-массив рычагов-правил, ничего кроме JSON:
```json
[
  {
    "id": "<стабильный slug, напр. post_surgery_x>",
    "condition": {"label": "<по-русски>", "detect": {"regex": "<regex по problem_list>"},
                  "qualifiers": ["post-surgical", "chronic", ...]},
    "fault": {"category": "metabolic|inflammatory|iatrogenic|mechanical|vascular|neurogenic",
              "mechanism": "<конкретный путь, не 'нарушение баланса'>"},
    "lever": "management | modify_enabling_condition",
    "frame": {"energy": "gain|maintain|standard", "protein": "high|standard",
              "micro": ["B12","iron","folate","D","Ca"],
              "constraints": ["lactose_free","sat_fat_limit","low_GI","purine_limit",
                              "dumping_aware","reflux_aware","portion_aware"]},
    "evidence": {"source": "WCRF|guideline|mechanism", "weight": "strong|moderate|supporting",
                 "why": "<простым языком>"}
  }
]
```

## Словарь (используй ТОЛЬКО эти токены)
- energy: gain | maintain | standard
- protein: high | standard
- micro: B12 | iron | folate | D | Ca
- constraints: lactose_free | sat_fat_limit | low_GI | purine_limit | dumping_aware | reflux_aware | portion_aware

Верни 3–8 правил, покрывающих реальные состояния пациента из входа. Ни слова вне JSON.
