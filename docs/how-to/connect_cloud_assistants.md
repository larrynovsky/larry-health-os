# Как подключить Health OS к Claude и ChatGPT

После подключения Claude и ChatGPT (в браузере и на телефоне) отвечают о здоровье по данным
Health OS: анализы, показатели приборов за день, медкарта, долгие факты памяти. Каждый ответ
инструмента несёт источник и дату; если данных нет, помощник получает «нет данных» и не должен
достраивать. Почему устроено так — [замысел](../explanation/mcp_gateway.md); что умеет каждый
инструмент — [справочник](../reference/mcp_tools.md).

**Для кого.** Сейчас сервер собирается только в установке владельца на Studio
(`scripts/install.py --owner-override`). Установка по [уроку первой установки](../tutorials/first_install.md)
его не включает.

**Что уходит наружу.** Ответы инструментов уходят в Anthropic (Claude) и OpenAI (ChatGPT) — тем,
кто задал вопрос. Имя, дата рождения и пути к бланкам из ответов вырезаны, медицинские данные — нет.

## 1. Разрешите отдельный узел в Tailscale

Сервер открывается в интернет своим узлом tailnet `health-mcp` через Funnel, чтобы публичный адрес
не открывал ни дашборд, ни другие службы машины. В политике доступа Tailscale (админка → Access
controls) добавьте владельца тега и право на Funnel:

```json
"tagOwners": { "tag:mcp": ["autogroup:admin"] },
"nodeAttrs": [ { "target": ["tag:mcp"], "attr": ["funnel"] } ]
```

Полезно добавить тест, что узел не видит остальные машины (замените адреса на свои):

```json
"tests": [ { "src": "tag:mcp", "deny": ["studio:22", "studio:8001", "studio:8002"] } ]
```

## 2. Включите сервер на Studio

```bash
mkdir -p ~/.health_mcp
docker volume create health_mcp-ts
cd ~/health_scripts && bash scripts/deploy_container.sh
```

Каталог `~/.health_mcp` — выключатель: пока он есть, перерисовка настроек добавляет службы `mcp`
(сервер) и `mcp-funnel` (узел tailnet). При первом старте узел просит войти в tailnet — ссылка в
журнале:

```bash
docker --context colima-health logs health-mcp-funnel-1 2>&1 | grep -m1 login.tailscale.com
```

Откройте ссылку, войдите своим аккаунтом и подтвердите узел в админке. Адрес сервера:
`https://health-mcp.<ваш-tailnet>.ts.net/mcp`. Публичная запись DNS иногда появляется не сразу.

## 3. Подключите Claude

В настройках Claude добавьте свой (custom) коннектор с адресом сервера из шага 2. Claude откроет
страницу «Подключение к Health OS»; код из шести цифр придёт в Telegram от бота Health OS.
Введите его на странице. Подключённый в браузере коннектор работает и в мобильном приложении.

## 4. Подключите ChatGPT

В ChatGPT свой коннектор подключается в режиме разработчика (настройки коннекторов). Адрес тот же,
вход тот же: код из Telegram.

## 5. Проверьте

Спросите помощника: «проверь связь с Health OS». Ответ инструмента `ping` — «Health OS на связи».
Затем вопрос, ответ на который вы знаете, например «какие анализы у меня есть». Новые инструменты
видны в новом чате: уже открытый чат знает только то, что было при его начале.

## Если код «истёк» или не пришёл

- Код живёт 10 минут, после пяти неверных попыток запрос сгорает — начните подключение заново.
- Код не пришёл в Telegram — вход отказывает сам («не удалось отправить код»): проверьте, что бот
  работает.

## Как закрыть доступ

Выключить сервер целиком (обратимо):

```bash
docker --context colima-health stop health-mcp-funnel-1
```

Отозвать все выданные токены — помощникам придётся войти заново:

```bash
docker --context colima-health exec health-mcp-1 python3 -c "import mcp_auth, os, pathlib; print(mcp_auth.Store(pathlib.Path(os.environ['HEALTH_DATA_DIR']) / 'data' / 'mcp_auth.sqlite').revoke_all())"
```

Команды отзыва в боте пока нет.
