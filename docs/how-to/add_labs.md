# Как добавить анализы

> Для тех, кто уже пользуется Telegram-ботом. Терминал для отправки бланков не нужен.
> Поведение сверено с кодом 02.10.2026; ограничения установки в Докере — ниже.

Скачайте бланк из кабинета лаборатории или сфотографируйте бумажный, отправьте боту,
затем сверьте распознанное с оригиналом. **Ответ «Получил» означает, что файл сохранён;
значения ещё не добавлены в ваши результаты.** Проверку и добавление вы завершаете
сами на своей странице — ссылка придёт в ваш чат с ботом.

## 1. Подготовьте бланки

- Лучше всего — исходный PDF с сайта лаборатории, где текст можно выделить.
  Сканированный PDF тоже принимается. Многостраничный PDF отправляйте одним файлом;
  по умолчанию предел — **20 страниц**. Более длинный файл не распознаётся частично:
  бот попросит разделить его на части не больше 20 страниц. Сохраните на них дату
  и название исследования и отправьте отдельными файлами.
- Бумажный бланк снимите целиком: ровно, при хорошем свете, без бликов. Должны читаться
  дата, названия показателей, числа, единицы и диапазоны нормы. Каждую страницу снимите
  отдельно и отправьте **как файл, без сжатия**, а не как обычное фото в чат.
  Подойдут JPG/JPEG и PNG. TIFF принимается, но многостраничный TIFF читается только
  с первого кадра: лучше сохранить его страницами в PDF или отдельными картинками.
- HEIC заявлен как входной формат, но в стандартном образе Докера для него нет
  нужного преобразователя. Сохраните снимок в JPG/PNG или PDF. HEIF не принимается
  разборщиком входящих.
- Excel (`.xlsx`, `.xls`) и CSV автоматически в анализы не загружаются. Сохраните
  таблицу в PDF так, чтобы колонки не обрезались, или возьмите PDF самой лаборатории.
- **ZIP с бланками распакуйте сами.** Автоматическая распаковка архивов относится к
  геному, а не к анализам; она не помогает обойти лимит размера бланка.

В стандартном образе распознавание текста настроено на **русский и английский**.
Для документов на другом языке попросите обслуживающего систему проверить поддержку;
способность модели прочитать язык сама по себе не гарантирует приём бланка.

«За 3 года» на главной карточке — ориентир для истории, а не условие загрузки.
Начните с того, что есть: одного свежего бланка достаточно для первого добавления.
Можно прислать более старые; дата исследования должна быть видна на самом бланке.

## 2. Отправьте файл в своего бота

1. Откройте чат с ботом, с которым проходили знакомство.
2. Нажмите скрепку → «Файл» (название зависит от приложения Telegram), выберите PDF
   или изображение. Для нескольких бумажных страниц отправьте отдельные файлы.
3. Дождитесь квитанции. Например, для PDF с именем `lab.pdf`:
   «Получил «lab.pdf». Анализы распознаю и пришлю на подтверждение; из заключения
   врача извлеку диагнозы и лекарства — тоже карточками на подтверждение.»
   Дополнение про заключение — общий текст квитанции; оно не означает, что в бланке
   нашлись диагнозы или лекарства.

Обычное фото в чат попадает в анализы только при отдельно включённом приёме таких
фото. Тогда бот может ответить «Похоже на бланк анализов — забрал в разбор. Распознаю
и пришлю на подтверждение.». На новой установке этот режим по умолчанию выключен:
ответ модели на фотографию ещё не означает загрузку анализов. Отправляйте фото файлом.

**Файл больше 20 МБ:** положите сам PDF или изображение в Google Drive, Dropbox,
Яндекс Диск или OneDrive, откройте доступ «всем, у кого есть ссылка» и пришлите ссылку
обычным сообщением. Ссылку прямо на кабинет лаборатории бот не скачивает.

Ответ: «Принял ссылку. Скачаю файл в фоне и разберу как обычный документ (геном,
анализы, заключение) — итог пришлю отдельным сообщением.» Затем, например:
«Получил «lab.pdf» (25.0 МБ). Разбираю.». После этого доступ по ссылке можно закрыть.
Лимит скачивания по ссылке — 3072 МБ; предел 20 страниц PDF остаётся.
Подробнее — [как прислать большой файл](send_large_file.md). В Докере путь к файлу
на вашем компьютере обычно не виден боту: используйте файл в чате или облачную ссылку.

## 3. Дождитесь распознавания и сверьте результаты

Разбор идёт в фоне: служба проверяет входящие раз в минуту и ждёт не менее 30 секунд
после сохранения файла. Дальше две модели читают каждую страницу. Отведите несколько
минут на небольшой бланк; это ориентир, гарантированного срока нет. Много страниц,
другие файлы в очереди или сбой сервиса модели увеличивают ожидание.

Прочитанные строки сначала лежат в отдельной очереди проверки (`staging`). Согласие
моделей может дать отметку `auto`, сомнение — `pending`. **Даже `auto` требует вашего
подтверждения:** ожидание не считается согласием и не добавляет числа в базу или отчёты.

Результат обработки приходит **вам в ваш чат с ботом**: имя файла, число распознанных
значений и ссылка на ваш лист сверки `/lab-review/<run_id>?tenant=<tenant>&show=waiting`.
Оператор не нужен для обычного подтверждения. При нескольких бланках главная карточка
**«Анализы»** показывает **«ждёт вас»** и число значений; кнопка **«Проверить распознанное»**
открывает самый старый незавершённый бланк. После его добавления карточка ведёт к следующему.

1. Откройте ссылку из сообщения на компьютере, где работает система. Для установки
   по [уроку первой установки](../tutorials/first_install.md) дашборд доступен по
   адресу `http://127.0.0.1:8001`. На телефоне этот адрес обозначает сам телефон:
   откройте страницу на компьютере или используйте настроенный частный доступ Tailscale.
2. Положите рядом исходный бланк. Сверьте названия, числа, единицы и нормы; посмотрите,
   нет ли пропущенных строк. Дата, материал пробы и знак `<`/`>` пока не показаны
   в листе — интерфейс не позволяет подтвердить правильность этих полей. Если строка
   вызывает сомнение, отметьте **«Ошибка»**; поля для исправления числа здесь нет.
3. Лист по умолчанию показывает все незавершённые строки, включая `auto`, `pending`,
   `review` и `gold`. **«Все строки бланка»** показывает также завершённые и отклонённые.
   **«Проверить»** проверяет возможность добавления, но уже сохраняет отмеченные ошибки
   и назначенные имена. **«Добавить в базу»** с вашим подтверждением переносит допустимые
   неотклонённые строки всего бланка, включая скрытые фильтром. Затем обновите главную.

**«🧪 Анализы»** в карточке выбора типа документа подтверждает только **тип бланка**,
а не прочитанные значения. Для чисел нужно отдельное подтверждение на листе сверки.
Открытие листа и молчание ничего не добавляют. Неизвестные названия, конфликты и
специальные панели могут потребовать отдельного решения; технические причины блокировки
описаны в [очереди ревью лабораторных строк](lab_review_queue.md).

## 4. Проверьте, что результаты появились

- В дашборде откройте **«Анализы»** (`/labs`) и обновите страницу. Там последние
  значения по показателям и последние 50 результатов из основной базы. Это страница
  просмотра; для очереди проверки используйте главную карточку «Анализы».
- В боте отправьте `/labs`. Он показывает выбранные ключевые показатели за последние
  два года и остальные показатели последнего визита из последних 90 дней, а не весь
  архив. Ответ «Результатов анализов пока нет.» сам по себе не доказывает, что старый бланк потерян.
- Принятые данные могут учитываться в следующих утренних отчётах. Отчёт не обязан
  перечислять все анализы и не заменяет проверку таблицы в дашборде.

Специальные исследования хранятся отдельно и могут не появиться на `/labs`.
Если после проверки нужного показателя нет, попросите обслуживающего систему
проверить его маршрут; повторная отправка того же файла не завершает перенос.

## Если что-то пошло не так

| Ответ или ситуация | Что сделать |
|---|---|
| «Не смог скачать файл. Пришли ещё раз. Без повторной отправки файл не получу.» | Повторите отправку файла |
| «Получил, но не смог сохранить. Попробуй ещё раз. Без повторной отправки файл не сохранится.» | Попробуйте ещё раз; если ответ повторяется, передайте его обслуживающему систему |
| ««lab.pdf» больше 20 МБ — Telegram не даёт боту скачать такой файл. Упакуй его в zip или пришли ссылку на файл (Google Drive, Dropbox, Яндекс Диск, OneDrive — с доступом по ссылке). Без доступного файла разбор не начнётся.» | Для анализов выберите ссылку на сам PDF: ZIP с бланками не разбирается |
| «Получил «lab.xlsx» и сохранил. Этот формат я пока автоматически не разбираю — в данные он сам не попадёт.» | Сохраните Excel/CSV в читаемый PDF и отправьте его |
| «Этот файл уже получал — пропускаю дубль.» | Файл с тем же содержимым повторно не разбирается, даже если переименован. Проверьте очередь и результаты; повторное распознавание поручите обслуживающему систему |
| «Этот кадр уже получал — второй раз в разбор не отдаю.» | Это ответ при включённом приёме обычных фото. Новый снимок того же листа может пройти как новый файл; сообщите о повторе при сверке |
| «Файл получил. Разбор сейчас на паузе — я передал это на починку, файл никуда не денется.» | Файл сохранён. Передайте сообщение обслуживающему систему: фраза не гарантирует автоматического ремонта вашей установки |
| Ссылка не скачивается или облако возвращает страницу вместо файла | Откройте доступ «всем, у кого есть ссылка» на само содержимое и пришлите ссылку ещё раз |
| Бланк нечёткий, после квитанции нет результатов или ссылки на сверку | Возьмите исходный PDF либо переснимите лист и отправьте новый файл. Бот пришлёт одно сообщение для этого файла с просьбой отправить оригинальный PDF или более чёткое фото; последующие опросы его не повторяют |
| Лист сверки не открывается на телефоне | Откройте его на компьютере с системой или попросите настроить частный доступ через Tailscale |
| Лист сверки пуст или после проверки ничего не появилось | Обновите главную: она открывает самый старый незавершённый бланк. Сверьте его и нажмите «Добавить в базу». Сохранённый файл и `auto` ещё не означают добавление; спорные или заблокированные строки требуют отдельного решения |
| PDF длиннее 20 страниц | Бот попросит разделить PDF на части по 20 страниц или меньше; из длинного файла строки не добавляются |
