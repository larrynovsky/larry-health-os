# Как выпустить новую версию образа

> **Тип документа:** How-to (Diátaxis). Для владельца. Выпуск — только по его команде
> (решение 30.09): новая версия сразу достаётся каждому, кто обновится по уроку.

Выпуск — это тег `vX.Y.Z` в открытом репозитории. Тег запускает `.github/workflows/release.yml`:
образ собирается на родных раннерах GitHub для amd64 и arm64, уходит в `ghcr.io` под номером
версии и `latest`, а выпуск GitHub получает три файла, которые скачивает урок: `compose.yaml`
(с именем этого образа), `health.env` и агент автозапуска Colima.

## 1. Выгрузите и дождитесь урока

```bash
cd ~/health_scripts
python3.11 scripts/public_mirror.py --push
```

Выгрузка запускает на GitHub `tutorial.yml`: урок первой установки исполняется на чистой машине
с образом из этого коммита. Дождитесь зелёного прогона:
`gh run list --repo larrynovsky/larry-health-os --workflow tutorial.yml --limit 1`.

## 2. Выпустите

```bash
python3.11 scripts/public_mirror.py --release v0.1.0
```

Команда откажет, если клон зеркала не совпадает с GitHub, если такой тег уже есть, если урок
на этом коммите не зелёный, если CodeQL ещё не разобрал этот коммит или на нём открыты находки
уровня critical/high (решение владельца 01.10). Ложную находку закрывают на вкладке Security
с причиной — тогда она выпуск не держит. Потом ждёт `release.yml` (около получаса, дольше всего arm64) и
сверяет файлы выпуска. Номер не переписывается: ошиблись — выпустите следующий.

## 3. Первый выпуск: откройте репозиторий, затем пакет

Урок берёт файлы выпуска со страницы репозитория, а образ — из пакета GHCR; закрыт любой из
двух — урок у других падает (файлы — 404, образ — `denied`). Открывает только владелец,
вручную, в таком порядке:

1. Репозиторий: Settings → Danger Zone → Change visibility → Public. Обратимо.
2. Пакет: GitHub → Your profile → Packages → `larry-health-os` → Package settings → Change
   visibility → Public. **Необратимо**: публичный пакет GitHub закрыть не даёт. Поэтому вторым —
   когда открытый репозиторий уже посмотрен.

Проверка — урок как у новичка, без входа в GitHub и GHCR, на машине без локальной копии образа:
`docker logout ghcr.io; python3 scripts/tutorial_run.py docs/tutorials/first_install.md --release`.

## Если изменились настройки

Урок при обновлении скачивает только `compose.yaml`: `.env` человека хранит его часовой пояс.
Если в выпуске поменялся состав `.env` (новый ключ), напишите это в описании выпуска на GitHub
(`gh release edit v0.1.1 --notes …`): урок велит в таком случае скачать `.env` заново.
