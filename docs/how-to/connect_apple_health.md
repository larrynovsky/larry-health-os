# Как подключить «Здоровье» iPhone и Apple Watch

> Тип документа: How-to (Diátaxis). Делает тот, кто ставил систему, вместе с владельцем телефона.

Данные приходят приложением Health Auto Export (iOS): оно само отправляет их на дашборд
системы, `POST /hae/ingest`, в формате JSON.

1. На основной машине создайте токен приёма и положите его в каталог секретов ЭТОГО
   человека (у второго человека установки — его `HEALTH_SECRETS_DIR`, например
   `~/.health_secrets_partner`):

   ```bash
   S=~/.health_secrets   # или каталог секретов второго человека
   openssl rand -hex 24 > $S/hae_ingest_token && chmod 600 $S/hae_ingest_token
   ```

   Токен передайте владельцу телефона вне чата с ботом.

2. Телефон должен видеть дашборд. После установки дашборд слушает только `127.0.0.1` —
   телефон его не видит. Поставьте Tailscale на основную машину и на телефон, узнайте
   адрес машины в частной сети (`tailscale ip -4`) и впишите его в `private/infra.yaml`
   строкой `studio_host: <этот адрес>`. Перезапустите дашборд:
   `launchctl kickstart -k gui/$(id -u)/com.larry.health.dashboard`.
   Проверка — `http://<этот адрес>:8001` открывается в Safari на телефоне. Не включайте для
   этого адреса `tailscale funnel`: авторизации у дашборда нет, открыть его в интернет —
   открыть всем свою медкарту.
3. В Health Auto Export создайте автоматизацию REST API:
   - URL: `http://<адрес дашборда этого человека>/hae/ingest` — у второго человека свой
     порт дашборда (тот же, куда уходит его локация);
   - заголовок `Authorization: Bearer <токен из шага 1>`;
   - формат Export Format — **JSON** (CSV система не читает), Summarize — включено.
4. Проверка: после первой отправки в каталоге данных появляется файл в `data/hae_rest/`,
   а в утреннем отчёте — шаги и пульс.

Почему дашборд именно этого человека: данные пишутся в базу того, чей процесс принял
запрос, а токен читается из секретов того же человека. Токен владельца на дашборде второго
человека не подходит, и наоборот — иначе один телефон мог бы писать в чужую базу.
