# Как прислать боту большой файл

> Для того, кто пользуется ботом и уже прошёл знакомство.

Файлы до 20 МБ присылайте прямо в чат — скрепкой, как документ. Бот ответит «Получил «<имя
файла>» … Разбираю.». Больше 20 МБ Telegram боту не отдаёт — чаще всего это сырые данные генома.

Файл с чипа (23andMe, AncestryDNA и другие из списка ниже) сначала попробуйте упаковать в `.zip`
(в Finder: правый клик → «Сжать»): такой текстовый файл сжимается в несколько раз, и если архив
меньше 20 МБ, присылайте его прямо в чат. Полный геном (VCF) в `.zip` не упаковывайте — бот его
оттуда не прочтёт; для него — облако. Остальное больше 20 МБ — тоже ссылкой на облако.

## Ссылкой на облако

1. Положите файл в Google Drive, Dropbox, Яндекс Диск или OneDrive. Других облаков и сайтов, в
   том числе iCloud Drive и WeTransfer, бот не знает: так он защищает машину от скачивания
   чего попало.
2. Откройте доступ «всем, у кого есть ссылка» (достаточно просмотра).
3. Пришлите ссылку боту обычным сообщением.

Бот ответит «Принял ссылку», а когда скачает — «Получил «<имя файла>». Разбираю.». Как только
пришло «Получил …», закройте доступ по ссылке: пока он открыт, файл может скачать любой, у кого
есть ссылка.

Сколько ждать. Файл с чипа (23andMe, AncestryDNA и другие из списка ниже) разбирается за
несколько минут, в конце придёт «Геном загружен: … вариантов» — у чипа это обычно сотни тысяч.
Полный геном (VCF) разбирается часы.

## Какие файлы подходят

- Сырые данные чипа: 23andMe, AncestryDNA, MyHeritage, FTDNA, tellmeGen (Starter/Advanced),
  LivingDNA. Можно прямо в `.zip`, как их отдаёт компания, — распаковывать не нужно.
- Полный геном в VCF: `.vcf` или сжатый `.vcf.gz` (tellmeGen Ultra, «Атлас» и другие). VCF **не**
  кладите в `.zip`: из архива он не читается, распакуйте. Предел — 3 ГБ на файл; несжатый VCF
  может не влезть, сжатый `.vcf.gz` в 4–5 раз меньше.
- Не подходят сырые прочтения секвенатора (FASTQ, BAM).

## Где окажется файл

Файл скачивается на машину, где работает система, и остаётся там после разбора — в каталоге
данных вашей установки, и сам собой не удаляется. Прочитать его может тот, кто управляет этой
машиной; если систему вам поставили на чужой компьютер, это его владелец. Удалить файл может тоже
только он.

## Если что-то пошло не так

| Что видите | Что сделать |
|---|---|
| «Не смог забрать файл: файл не найден или доступ по ссылке закрыт» | Откройте доступ «всем, у кого есть ссылка» и пришлите ссылку ещё раз |
| «облако вернуло страницу вместо файла» | То же: облако показывает страницу входа вместо файла, когда доступ закрыт |
| «… больше 3072 МБ …» | Пришлите сжатый `.vcf.gz` |
| На ссылку бот отвечает как на обычное сообщение, «Принял ссылку» не пишет | Ссылка не из четырёх облаков выше. Переложите файл туда |
| «… похоже на генетические данные в формате …, такой я пока не загружаю» | Формат не из списка выше. Ищите у компании выгрузку «сырых данных» в поддерживаемом виде |
| После «Получил … Разбираю» прошло полчаса для чипа (или сутки для VCF), а «Геном загружен» не пришёл | Скажите тому, кто обслуживает установку, или напишите разработчикам в [issues](https://github.com/larrynovsky/larry-health-os/issues) |

Второй геном поверх уже загруженного бот не загружает, чтобы не затереть ваш геном чужим.
Полный геном (VCF) поверх своего чипа — можно: он уточняет данные. Если VCF сильно расходится с
чипом, бот ничего не записывает и отвечает, что это, похоже, геном другого человека. Заменить
загруженный геном на другой бот не умеет — это делает тот, кто обслуживает установку, вручную;
инструкции для этого пока нет.

## Путём к файлу — только в установке без Докера

Если система стоит без Докера (из клона репозитория) и файл лежит на той же машине, можно
прислать его полный путь, например `/Users/anna/Downloads/genome.zip` (в Finder: правый клик по
файлу, зажмите Option → «Скопировать путь до …»). Бот ответит «Принял путь». Бот читает путь с
правами своей учётной записи: на машине, где ботом пользуются несколько человек, он может взять
и чужой файл.

В установке в Докере путь не работает: контейнер не видит папок Мака, и бот ответит, что не
видит файлов на этом компьютере. Пользуйтесь облаком.
