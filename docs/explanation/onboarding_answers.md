# Знакомство: куда ложится каждый ответ и почему именно туда

> Тип документа: Explanation (Diátaxis). Как пройти — [redo_onboarding](../how-to/redo_onboarding.md);
> вопросы — `methodology/instruments/onboarding.json`; поля профиля — `methodology/profile_fields.yaml`.

Первая мысль: знакомство — это не анкета, которую потом кто-то разбирает. Каждый ответ сразу
записывается туда, откуда его читает код. Если ответ сохраняется в файл без потребителя,
он не попадает в профиль и не влияет на следующий отчёт. Сохранение само по себе
не доказывает, что система учла ответ.

## Куда что идёт

| Вопрос | Куда | Кто читает |
|---|---|---|
| имя, дата рождения, пол, рост, вес, курение, анализы натощак | `patient_profile` (через `profile_db.apply_stated`, та же проверка, что у разговора) | отчёт врача, нормы по полу и возрасту, индекс массы тела в своде состояний |
| дом | `system_config` `location.home_lat/lon` | отличие дома от поездок; из дома — часовой пояс отчёта |
| время отчёта | `system_config` `schedule.morning_brief` | расписание утреннего отчёта (пересчитывается сразу) |
| проблемы со здоровьем | предложения в список проблем, по одному на строку | человек подтверждает `/approve` — только потом медкарта |
| лекарства и добавки | `medications`, словами человека | сводка лечения, контекст врача |
| что подключить | задачи-действия с инструкцией | список задач человека |

## Почему проблемы — через подтверждение, а лекарства — нет

Список проблем — медкарта. В неё пишет только нажатие человека: так устроено для всех
источников, включая модель-врача (запись реестра `problem_list_proposals.owner_gate_kept`).
Знакомство не исключение. Лекарства записываются сразу: это собственные слова человека,
модель их не разбирала, искажать нечему.

## Чего знакомство намеренно не спрашивает

Тип диабета, аллергии, группу крови (решение владельца 23.09): «сами расскажут или дадут
результаты обследования». Правило общее: вопрос попадает в знакомство, только если у ответа
есть читатель в коде. Ответ, который никто не прочтёт, хуже отсутствия вопроса — он выглядит
учтённым.

## Граница

Токены сервисов (Oura, «Здоровье» iPhone) через чат не принимаются: сообщение Telegram живёт
на чужих серверах. Знакомство только ставит задачу «подключить» со ссылкой на инструкцию.
