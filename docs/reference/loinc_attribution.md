# Атрибуция LOINC

Система использует **LOINC®** (Logical Observation Identifiers Names and Codes)
как единственный дом канонического имени лабораторного аналита.

- **Версия релиза:** 2.82
- **Загружено:** подмножество Universal Lab Orders (заказываемые лабораторные
  тесты), поля из LoincTableCore. Полный справочник не грузится осознанно —
  см. `loinc_loader.py`, раздел «ГРАНУЛЯРНОСТЬ».
- **Правообладатель:** LOINC является зарегистрированным товарным знаком
  Regenstrief Institute, Inc. LOINC и связанный с ним контент публикуются
  Regenstrief Institute и комитетом LOINC.
- **Условия использования** проверены владельцем системы лично 2026-07-29.

## Почему этот файл существует

Атрибуция — обязательство, а обязательство без носителя исчезает при первом
рефакторинге. Наличие файла и слова LOINC в нём стережёт
`tests/unit/test_loinc_loader.py::test_attribution_document_exists`: удаление
документа красит прогон, а не проходит незамеченным.

## Что здесь НЕ написано

Полный текст лицензии не пересказывается: пересказ юридического документа —
второй дом, который расходится с первоисточником молча. Первоисточник —
файл лицензии внутри релизного архива LOINC.
